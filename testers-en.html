Why testers are needed

StaySafe uses features that may behave differently depending on the phone model, Android version and manufacturer settings. Real testing is essential.

📱

Different phones

Samsung, Xiaomi, Motorola, Oppo, OnePlus and other phones may handle notifications, background services and full-screen alerts differently.

🚨

Critical features

We are testing SOS, fall detection, GPS location, automatic calling and emergency alerts.

🛠️

Real feedback

Every reported issue helps improve the app before the official launch.

What should be tested?

1. Installation and permissions

Check if the app installs correctly and if SMS, location, call and notification permissions are clearly requested.

2. Manual SOS

Test the SOS button, countdown, location message and behavior after activation.

3. Fall detection

Enable fall detection, test the sensitivity slider and check whether the alert appears automatically.

4. Full-screen alert

Lock the screen, simulate a fall and check whether the red alert screen appears without opening the app manually.

5. Emergency file

Fill in test information and check whether it appears correctly on the emergency screen.

6. Danger mode

Test the sound alarm, flashing light and alarm stop behavior.

How to send feedback

Please include as many details as possible. You do not need technical language. Just explain what you did and what happened.

Recommended feedback format

  • Phone model: for example Samsung Z Fold 5, Motorola Edge 40, Xiaomi Redmi, etc.
  • Android version: for example Android 13, Android 14, Android 15.
  • Tested feature: SOS, fall detection, full-screen alert, emergency file, danger mode.
  • What happened: short description of the issue or confirmation that it worked.
  • Screenshot / video: optional, but very useful if an error appears.
